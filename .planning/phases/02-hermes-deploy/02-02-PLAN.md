From Research §Pattern 1 — hardened systemd unit:
```ini
[Unit]
Description=ultra-workshop Hermes Agent gateway
After=network-online.target uab-brain.service
Wants=network-online.target
Requires=uab-brain.service

[Service]
Type=simple
User=uws
Group=uws
WorkingDirectory=/opt/ultra-workshop
EnvironmentFile=/etc/uws/env
Environment=HERMES_INSTALL_DIR=/opt/ultra-workshop/hermes
Environment=HOME=/home/uws
Environment=PATH=/home/uws/.local/bin:/opt/ultra-workshop/hermes/hermes-agent/.venv/bin:/home/uws/.nvm/versions/node/v24/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
ExecStart=/opt/ultra-workshop/hermes/hermes-agent/.venv/bin/hermes gateway start
Restart=on-failure
RestartSec=10
StartLimitIntervalSec=120
StartLimitBurst=5
MemoryMax=4G
CPUQuota=200%
NoNewPrivileges=true
PrivateTmp=true
ProtectSystem=strict
ProtectHome=true
ReadWritePaths=/home/uws/.hermes /var/log/ultra-workshop /tmp
StandardOutput=journal
StandardError=journal
SyslogIdentifier=uws-hermes

[Install]
WantedBy=multi-user.target
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local→VPS (SSH/rsync) | install.sh pushes files as root; unit file and config must not carry secrets |
| hermes-config/config.yaml | In-repo config — must have zero secrets; secrets come only from /etc/uws/env via ${VAR} |
| uws process boundary | Hermes runs as uws; ProtectSystem=strict limits write access to declared ReadWritePaths |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | Information Disclosure | hermes-config/config.yaml in git | mitigate | No secrets in file; verify in service-up.bats (grep for token/sk-/ghp_ patterns must return 0) |
| T-02-06 | Elevation of Privilege | MCP subprocesses spawned by Hermes | mitigate | NoNewPrivileges=true + PrivateTmp=true in unit; uws is a system account (no sudo) |
| T-02-07 | Tampering | Hermes install script from GitHub curl | mitigate | Pin HERMES_INSTALL_DIR; review script before piping to bash; installer is from official NousResearch repo |
| T-02-08 | Denial of Service | MemoryMax exceeded under Aider load | accept | MemoryMax=4G is hard limit; Phase 3 will calibrate based on actual Aider usage |
| T-02-SC | Tampering | npm/pip/cargo installs | mitigate | No package-manager installs in this plan (Hermes installer uses uv internally — trust chain verified in research) |
