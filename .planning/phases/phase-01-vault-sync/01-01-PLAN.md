<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mac → GitHub | gh CLI pushes using user's OAuth token (trusted) |
| VPS uabrain → GitHub | SSH deploy key with write access; key file is 600, owned by uabrain |
| cron → git-sync.sh | Runs as uabrain, not root; limited to vault dir operations |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | SSH deploy key | mitigate | ed25519 key, no passphrase (required for unattended cron), file mode 600, owned by uabrain only |
| T-01-02 | Tampering | /srv/second-brain git history | mitigate | ff-only merge in git-sync.sh pull; conflict exits non-zero; cron failure alerts via health-check |
| T-01-03 | Information Disclosure | deploy key private file | mitigate | key stored at /home/uabrain/.ssh/, not in repo, not in env vars |
| T-01-04 | Elevation of Privilege | cron runs as uabrain | accept | uabrain is a restricted system user; vault dir is its primary write zone; no sudo in git-sync.sh |
| T-01-SC | Tampering | npm/pip installs | accept | Phase 1 has no package installs; git-sync.sh uses only system git |
</threat_model>
