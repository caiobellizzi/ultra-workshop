Obsidian-Git is a community plugin. The plugin files must be placed in the vault's
.obsidian/plugins/obsidian-git/ directory. The standard install method is:
  git clone https://github.com/denolehov/obsidian-git \
    ~/Documents/second-brain/.obsidian/plugins/obsidian-git
  (or download the latest release assets main.js + manifest.json + styles.css)

  - "autoSaveInterval": 5          (minutes, commit+push)
  - "autoPullInterval": 5          (minutes, pull)
  - "autoPullOnBoot": true
  - "commitMessage": "vault: auto-sync {{date}}"
  - "autoCommitMessage": "vault: auto-sync {{date}}"

The Mac uses the user's personal SSH key (~/.ssh/id_ed25519 or similar) for GitHub,
not the VPS deploy key. The Mac vault has no remote yet — it must be added.
