## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Hermes skill body → aider_runner.py | --task arg comes from user message; passed to subprocess |
| aider_runner.py → aider subprocess | task string passed as --message positional arg; no shell expansion |
| aider subprocess → LiteLLM proxy | Aider talks to 127.0.0.1:4000 (trusted loopback) |
| aider_runner.py → brain_http.py (cost record) | fire-and-forget; failure is silently caught |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-16 | Tampering | aider_runner.py --task arg command injection | mitigate | subprocess.run([...], shell=False) with task as positional --message arg; no shell string concatenation; no eval |
| T-03-17 | Information Disclosure | LITELLM_API_KEY in subprocess env | mitigate | API key read from os.environ["LITELLM_API_KEY"] (not hardcoded); not logged; not printed to stdout |
| T-03-18 | Elevation | aider writes to /tmp/uws-aider-workspace | accept | Workspace is /tmp (world-writable); aider runs as uws user; changes are in tmp only; no production code path without explicit user action |
| T-03-19 | Tampering | aider_runner.py workspace path injection | mitigate | workspace_dir defaults to Path("/tmp/uws-aider-workspace") (absolute, hardcoded); caller cannot override via CLI args in current impl |
| T-03-20 | Tampering | aider-chat [ASSUMED] package installation | mitigate | pip install aider-chat is blocked on human verification per Package Legitimacy Gate — see checkpoint T-03-SC |
| T-03-SC | Tampering | aider-chat PyPI package (ASSUMED) | mitigate | Package Legitimacy Gate: aider-chat (pypi.org/project/aider-chat — widely known, 50k+ GitHub stars, Paul Gauthier MIT); human must confirm at install checkpoint before VPS pip install runs |
</threat_model>
