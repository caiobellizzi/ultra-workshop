## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-17 | Tampering | aider --message task arg injection | mitigate | task string passed as list element to subprocess.run([..., "--message", task, ...], shell=False); no shell expansion; subprocess receives it as a single argument |
| T-03-18 | Information Disclosure | LITELLM_API_KEY in aider subprocess environment | mitigate | Key read from os.environ["LITELLM_API_KEY"] (set in /etc/uws/env); passed as --openai-api-key arg (list element, not shell string); not printed to stdout |
| T-03-19 | Denial of Service | aider subprocess running indefinitely | mitigate | --no-stream + --yes-always + --max-turns (aider's own iteration cap); subprocess.run has no timeout set by default — consider adding timeout=300 to subprocess.run for production hardening |

| T-03-21 | Spoofing | private-worker unreachable but smoke passes | mitigate | V5 strict: skip_if_private_worker_down() gates all live tests; bats exits 0 only when SKIP or PASS — never passes silently on missing private-worker |
| T-03-SC | Tampering | aider-chat PyPI package legitimacy | mitigate | Installed in Wave 0 (Plan 01 Task 1); [ASSUMED] Approved status confirmed there; 50k+ GitHub stars, paul-gauthier/aider well-known repo |
