| VPS shell → hermes-skill-run.sh → hermes chat | SKILL and QUERY come from caller; passed to hermes as argv args (not shell string) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | hermes-skill-run.sh — SKILL arg | mitigate | SKILL captured as $1 (positional); passed to exec as quoted "$SKILL" — no word-splitting; hermes chat validates skill existence |
| T-03-02 | Tampering | hermes-skill-run.sh — QUERY string | mitigate | QUERY passed as "$QUERY" to hermes chat; exec (not eval, not sh -c) prevents shell injection |
| T-03-03 | Elevation | hermes-skill-run.sh — sudo -u uws | accept | Wrapper runs as root on VPS and drops to uws for Hermes; sudo policy already in place from Phase 2; uws is unprivileged |
| T-03-SC | Tampering | No npm/pip/cargo installs in this plan | accept | Wave 0 is pure shell + Python stdlib; no package installs |
