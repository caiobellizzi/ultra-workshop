| skill name string → output path | Skill directory names used to construct output paths |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Tampering | audit-claude-skills.py — skill name → output path | mitigate | pathlib.Path(name).name strips path components; assert ".." not in safe_name; all writes constrained to HERMES_TRANSLATED_ROOT |
| T-03-05 | Tampering | audit-claude-skills.py — reading arbitrary SKILL.md body | accept | Script only reads files inside ~/.claude/skills/; no execution of SKILL.md content; pure regex scan |
| T-03-06 | Information Disclosure | skill-audit.json written to repo root | accept | skill-audit.json contains skill names/categories only — no secrets; gitignore can be added if desired |
| T-03-07 | Elevation | --apply overwrites files in ~/.hermes/skills/translated/ | mitigate | Idempotency check (hash compare) prevents spurious overwrites; translated/ dir is staging only — never auto-promoted to live skills |
| T-03-SC | Tampering | No npm/pip/cargo installs (stdlib only) | accept | Pure Python stdlib — no package installs in this plan |
