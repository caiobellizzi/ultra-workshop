## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-03-05 | Tampering | audit-claude-skills.py — skill name → output path | mitigate | Path(skill_name).name strips traversal components; assert ".." not in safe_name; all writes constrained to HERMES_TRANSLATED_ROOT subtree |
| T-03-06 | Tampering | reading arbitrary SKILL.md body content | accept | Script only reads files inside ~/.claude/skills/; no execution of SKILL.md content; pure regex scan for tool names |
| T-03-07 | Information Disclosure | skill-audit.json written to repo root | accept | Contains only skill names and categories — no secrets; add to .gitignore if desired |
| T-03-08 | Tampering | --apply overwrites files in translated/ | mitigate | Idempotency check (content comparison) prevents unnecessary overwrites; translated/ is staging only and never auto-promoted to live skills |
| T-03-SC | Tampering | No package installs (stdlib only) | accept | Pure Python stdlib; no pip calls in this plan |
