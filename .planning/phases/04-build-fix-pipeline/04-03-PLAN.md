- If --dry-run: print "[dry-run] would run workshop pipeline", print the resolved task/issue args, sys.exit(0)
- task_id = f"workshop/{secrets.token_hex(2)}-{(task or issue_url).replace(' ', '-')[:20]}"

- Import and call run_triage, run_planner, run_coder, run_reviewer, run_pr_opener from workshop.nodes
- Pipeline loop (run once, reviewer-coder retry max 2):
  1. triage_result = run_triage(task_id, task or issue_url)
  2. plan = run_planner(task_id, task or issue_url, triage_result)
  3. diff = run_coder(task_id, plan)
  4. review = run_reviewer(task_id, plan, diff)
  5. If not review.passed and retry_count < 2: increment retry_count, re-run coder + reviewer; else proceed
  6. pr_url = run_pr_opener(task_id, diff.branch, plan, diff, session_id, chat_id)
- write_task_ledger(task_id, task or issue_url, status="completed" if pr_url != "REJECTED" else "rejected", pr_url=pr_url)
- print(f"[workshop] done — pr_url={pr_url}", flush=True)
- if __name__ == "__main__": main()
