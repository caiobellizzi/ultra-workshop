<objective>
Write the two entry-point scripts (workshop_build.py, workshop_fix.py), the two Hermes SKILL.md wrappers, deploy everything to VPS, and run smoke tests.

Architecture B HITL pattern (CRITICAL):
- workshop_build.py runs triage→planner→coder→reviewer via run_specialist() (subprocess per role)
- At the pr_opener stage it does NOT call run_specialist; instead it emits a JSON approval request to stdout and calls sys.exit(2)
- SKILL.md body catches exit code 2, reads the JSON from stdout, calls `clarify` with the summary
- On user approval: SKILL.md body calls `terminal python3 /opt/ultra-workshop/hermes-skills/workshop_push.py --task-id ... --branch ... --workspace-dir ...`
- On user rejection: SKILL.md body records rejection and stops

This is the proven pattern from skills/aider/SKILL.md (terminal python3 + SKILL.md body control flow).

Purpose: This is the capstone plan for Phase 4. When it completes, /build or /fix from Telegram reaches the HITL gate and, on approval, produces a pull request. The smoke tests provide a permanent regression guard.
Output: Two entry-point scripts, two SKILL.md files, three test files, workshop/ package deployed on VPS, all smoke tests green.
