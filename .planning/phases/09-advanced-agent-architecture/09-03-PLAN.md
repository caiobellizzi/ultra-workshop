<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| review-roster.yaml → wave dispatcher | Untrusted config file drives reviewer selection — malformed or missing file must fail-safe |
| brain query result → requirements gate | Prior clarifications from brain are injected into planning context — must not override current-task requirements |
| ThreadPoolExecutor → reviewer subprocesses | Parallel subprocess dispatches share the host process environment |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-03-01 | Tampering | review-roster.yaml missing/malformed | mitigate | load_review_roster() raises ValueError; always-on fallback hardcodes correctness+security so security is never silently skipped |
| T-09-03-02 | Denial of Service | all 8 reviewers timing out, blocking pipeline | mitigate | Per-reviewer timeout from stage_policy; ThreadPoolExecutor.result(timeout=N) per worker; wave-level timeout = max(per-reviewer timeout) + 60s buffer (not sum) |
| T-09-03-03 | Information Disclosure | brainstorm goal_statement leaked to non-brainstorm stages | accept | goal_statement stored in task state and passed to triage — this is intentional; no external exposure |
| T-09-03-04 | Tampering | brain prior_clarifications overriding current task requirements | mitigate | _query_prior_clarifications result is injected into planning_notes only, not into the primary requirements evaluation path; current task spec takes precedence |
| T-09-03-05 | Elevation of Privilege | reviewer subprocess inheriting write access to workspace | mitigate | Per D-06: reviewers receive frozen diff JSON only; workspace_dir not passed to reviewer subprocesses |
| T-09-03-SC | Tampering | dependency installs | mitigate | No new pip installs — ThreadPoolExecutor is stdlib (concurrent.futures), yaml is PyYAML already in requirements |
</threat_model>
