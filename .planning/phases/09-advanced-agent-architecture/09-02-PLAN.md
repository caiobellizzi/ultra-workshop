| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-09-02-02 | Spoofing | severity label mismatch between soul output and ReviewFinding model | mitigate | ReviewFinding field_validator (implemented in 09-01) normalizes and rejects unknown values; each soul Output Schema section documents the exact Literal["Critical","Important","Minor"] values |

| T-09-02-04 | Elevation of Privilege | reviewer soul with write access to workspace | mitigate | All reviewers (except merge-agent) read frozen diff only per D-06; prohibited in agent-isolation-policy.md "Prohibited Patterns" section |
| T-09-02-SC | Tampering | dependency installs | mitigate | No new pip installs — workshop/worktree.py uses subprocess + stdlib only |
