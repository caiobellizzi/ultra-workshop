       `result = call_agent("query", f"find document: {doc_name}")` with 60s timeout.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| doc_name input → vault/workspace rglob | doc_name originates from user task string or planner output — untrusted |
| Brain HTTP response → planner context | Brain may return crafted content; content is injected as reference, not trusted instructions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-02-01 | Tampering | resolve_doc doc_name validation | mitigate | Validate doc_name: reject "..", leading "/", null bytes with ValueError before any filesystem access. `[ASVS V5.1.1]` |
| T-07-02-02 | Information Disclosure | vault rglob reads arbitrary vault files | mitigate | rglob is constrained to vault_path root; doc_name cannot escape via traversal after validation |
| T-07-02-03 | Spoofing | Brain HTTP returns injected doc content | accept | Content injected as "reference_doc" field in planner query, labelled as reference not instructions per SKILL.md; planner model sees it as context, not tool config |
| T-07-02-04 | Elevation | workspace_dir path empty or crafted | mitigate | workshop_build.py (Plan 04) validates workspace_dir is under /tmp/uws-workspace-*/ before passing to resolve_doc; doc_resolver receives it as-is but doc_name traversal guard is the critical control |
| T-07-02-SC | Tampering | npm/pip/cargo installs | accept | No new packages; stdlib + existing pydantic/brain_http |
</threat_model>
