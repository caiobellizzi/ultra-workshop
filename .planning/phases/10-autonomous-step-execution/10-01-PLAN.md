# Phase 10: Autonomous Step-by-Step Build Execution

## Goal

Transform the coder from a single monolithic Aider invocation into an ordered per-step execution loop — one PlanStep = one Aider call = one commit — with per-stage NIM model routing, idle watchdog timeouts, bounded auto-recovery, and mid-plan resume via step cursor. Fixes the root cause of `ws-ai-briefing-0526a` timing out at 900s with zero edits.

## Constants (locked for this plan)

- `UWS_IDLE_TIMEOUT` = 120s (env-configurable; default 120)
- `UWS_STEP_MAX_TIMEOUT` = 600s (absolute backstop per step)
- `UWS_TASK_BUDGET` = 2400s (total wall-clock budget for the full task)
- `UWS_CODER_MAX` = 7200s (orchestrator backstop for multi-step coder stage)
- `MAX_STEPS` = 20 (planner global cap; "PRD too large" signal if exceeded)
- `MAX_STEP_RETRIES` = 2 (in-step build/test retry cap before recovery ladder)
- `DECOMPOSE_DEPTH_MAX` = 1 (one auto-decompose attempt per step)

## Model Alias Wiring

`stage_policy.py` injects `"model_alias": MODEL_ALIASES[stage]` into each stage's query payload. `workshop_coder.py` reads `model_alias` from the payload it receives (coder stage → `"coder-worker"`) and passes a single `model_alias` to `_run_aider_runner` for all steps in the loop. No per-step model selection needed from the planner — all coder steps use the coder stage's alias.

| Stage | Alias |
|-------|-------|
| triage-specialist | cheap-fast |
| requirements-specialist | cheap-fast |
| planner-specialist | planner-reasoner |
| coder-specialist | coder-worker |
| reviewer-specialist | reviewer-model |

1. Read `model_alias` from the coder stage's received payload (set by stage_policy.py; default "coder-worker").
2. Loop over `plan["steps"]`:
   ```python
   for step_idx, step in enumerate(plan["steps"]):
       step_msg = step.description  # or build from description + context
       step_files = step.files      # only this step's files, not all affected_files
       
       # Attempt execution with retries (MAX_STEP_RETRIES = 2)
       for retry in range(MAX_STEP_RETRIES + 1):
           result = _run_aider_runner(model_alias=model_alias, message=step_msg, files=step_files)
           passed, output = run_build_test_gate(result)
           if passed:
               break
           step_msg = f"{step.description}\n\nPrevious attempt failed:\n{output}"  # inject failure
           if retry == MAX_STEP_RETRIES:
               raise StepRetryExhausted(step_idx=step_idx, output=output)
       
       # Commit the step
       git_commit_step(task_id, step_idx, step.description)
       
       # Persist cursor
       save_task_state(task_id, current_step=step_idx + 1)
   ```
3. Branch reset (`git checkout default_branch`) only at task START — never between steps. Prior steps' commits must survive on the `workshop/<task_id>` branch.

3. Kill via `_terminate_process_group` if `time.monotonic() - last_output_at > IDLE_TIMEOUT`:
