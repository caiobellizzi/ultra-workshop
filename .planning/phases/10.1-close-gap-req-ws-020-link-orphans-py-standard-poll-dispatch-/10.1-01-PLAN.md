| stdin → telegram_alert.main() | Same source — cron_standard_poll pipes the queue entry |
| cron_standard_poll → subprocess | Entry fields (repo, task, issue_url) become CLI argv; must not allow shell injection |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10.1-01 | Tampering | cron_standard_poll._dispatch_entry build/fix | mitigate | subprocess.run uses list form (never shell=True); entry.get("task","") fallback prevents KeyError; base64 encoding of task string eliminates quoting/injection via argv |
| T-10.1-02 | Tampering | link_orphans.py stdin parse | mitigate | json.loads with explicit JSONDecodeError catch; sys.exit(1) on parse failure prevents malformed data from propagating |
| T-10.1-03 | Tampering | telegram_alert.main() stdin parse | mitigate | json.loads with SystemExit on JSONDecodeError; malformed input terminates cleanly |
| T-10.1-04 | Denial of Service | cron_standard_poll subprocess timeout | mitigate | timeout=1800 on all subprocess.run calls; TimeoutExpired caught and logged; does not crash the dispatcher |
| T-10.1-05 | Information Disclosure | telegram_alert.send_alert token | accept | TELEGRAM_BOT_TOKEN read from env at call time (not module-level); RuntimeError raised if absent — token never in source |
