# Plan 05-01: Brain Dispatched-ACK Endpoint

## Goal
Add `PUT /workshop/queue/{entry_id}/dispatched` to ultra-agents-brain so that the fast-poll service can mark queue entries as dispatched after acting on them.

## Context
ultra-agents-brain already exposes `PUT /workshop/repos` via `agentos/workshop_registry.py`, registered in `app.py` by inserting at position 0 of `app.router.routes` (to beat the catch-all sub-app). The queue file lives at `vault/_system/.workshop-queue.jsonl` — one JSON object per line, each with an `id` field. No queue-related code exists in either repo yet. This plan creates the Brain-side route handler and the ultra-workshop-side HTTP helper that cron skills will call.

## Requirements
- REQ-ws-021 (dispatched-ACK signaling between Brain and Workshop)

## Tasks

### Task 1: Brain route — `PUT /workshop/queue/{entry_id}/dispatched`
**File:** `ultra-agents-brain/agentos/workshop_queue.py` (new)
**What:** Create a new module with a single public function `register_queue_routes(app: Any) -> None` that inserts a `PUT /workshop/queue/{entry_id}/dispatched` route at position 0 of `app.router.routes` (same pattern as `register_workshop_routes`).

Route logic:
1. Read the JSONL queue file at `Path(os.environ.get("WORKSHOP_QUEUE_PATH", "/srv/second-brain/_system/.workshop-queue.jsonl"))`. If the file does not exist, return `{"ok": False, "error": "queue file not found"}` with HTTP 404.
2. Parse each line as JSON (skip blank lines). Find the entry whose `"id"` field equals `entry_id` (path param, str). If not found, return HTTP 404 with `{"ok": False, "error": "entry not found"}`.
3. Set `entry["dispatched"] = True` on the matching entry. Write back atomically: `json.dumps` each entry to a temp file in the same directory, then `os.replace(tmp, queue_file)` — same atomic rename-swap pattern used elsewhere in the codebase.
4. Return `{"ok": True, "entry_id": entry_id}`.

Use `fastapi.HTTPException` for error responses. Import `os`, `json`, `tempfile`, `pathlib.Path`. No external dependencies beyond what FastAPI already provides.

**Acceptance:** `python -c "import agentos.workshop_queue; print('ok')"` succeeds from the Brain virtualenv.

### Task 2: Wire route into `app.py`
**File:** `ultra-agents-brain/agentos/app.py` (modify)
**What:** After the existing `register_workshop_routes(app)` call, add:
```
from agentos.workshop_queue import register_queue_routes
register_queue_routes(app)
```
No other changes to `app.py`.

**Acceptance:** `curl -s -o /dev/null -w "%{http_code}" -X PUT http://127.0.0.1:7000/workshop/queue/nonexistent/dispatched` returns `404` (not `405` or `500`).

### Task 3: ultra-workshop HTTP helper — `mark_queue_entry_dispatched`
**File:** `hermes-skills/brain_http.py` (modify)
**What:** Append the following function after the existing `call_agent` function:

```python
def mark_queue_entry_dispatched(entry_id: str) -> dict:
    """PUT /workshop/queue/{entry_id}/dispatched — mark queue entry as dispatched.

    Raises httpx.HTTPStatusError on non-2xx response.
    """
    resp = httpx.put(
        f"{BRAIN_BASE_URL}/workshop/queue/{entry_id}/dispatched",
        timeout=10,
    )
    resp.raise_for_status()
    return resp.json()
```

Use `BRAIN_BASE_URL` (already defined as `"http://127.0.0.1:7000"` at module top). Import is already `import httpx` — no new imports needed.

**Acceptance:** `grep -c "mark_queue_entry_dispatched" hermes-skills/brain_http.py` returns `1`.
