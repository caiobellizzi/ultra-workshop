# Plan 05-03: Bug-Scan Fast-Poll systemd Service

## Goal
Ship the 30-second fast-poll loop as a standalone Python script and its systemd unit file so queue entries with `action` + `confirmed: true` + `dispatched: false` are dispatched automatically, around the clock except for the 22:00–07:00 quiet window.

## Context
The queue file is `vault/_system/.workshop-queue.jsonl` (path from `VAULT_VPS_PATH` env). `brain_http.mark_queue_entry_dispatched(entry_id)` (created in Plan 05-01) handles the ACK step. `workshop_build.py` and `workshop_fix.py` are the dispatch targets for `build` and `fix` actions respectively. Zero-HITL verbs (`post-to-telegram`, `link-orphans`) are pre-approved and bypass any approval gate. The service must run as `uws` user with `/etc/uws/env` loaded via `EnvironmentFile`. A PID file at `/tmp/uws-fastpoll.pid` prevents duplicate instances.

## Requirements
- REQ-ws-019 (fast-poll 30s dispatch loop)
- REQ-ws-020 (quiet-hours deferral 22:00–07:00)
- REQ-ws-021 (dispatched-ACK after dispatch)

## Tasks

### Task 1: `cron_bug_scan_fastpoll.py` — the infinite poll loop
**File:** `hermes-skills/cron_bug_scan_fastpoll.py` (new)
**What:** Standalone Python script. When executed directly (`python cron_bug_scan_fastpoll.py`) it runs forever. The systemd unit's `ExecStart` points here.

Structure:

**Single-instance lock** (at module top, before the loop):
```python
import os, sys
PID_FILE = "/tmp/uws-fastpoll.pid"
pid_path = Path(PID_FILE)
if pid_path.exists():
    existing_pid = pid_path.read_text().strip()
    try:
        os.kill(int(existing_pid), 0)  # signal 0 = existence check
        print(f"Already running (pid {existing_pid}), exiting.", file=sys.stderr)
        sys.exit(0)
    except (ProcessLookupError, ValueError):
        pass  # stale PID file — continue
pid_path.write_text(str(os.getpid()))
```
On exit (via `atexit.register` or `try/finally`): remove the PID file.

**Quiet-hours check** helper:
```python
def _in_quiet_hours() -> bool:
    h = datetime.datetime.now().hour
    return h >= 22 or h < 7
```

**Main loop** (inside `if __name__ == "__main__"` block, wrapped in `try/finally` for PID cleanup):
```python
while True:
    try:
        _poll_once()
    except Exception as e:
        logging.error("poll_once error: %s", e)
    time.sleep(30)
```

**`_poll_once()` function:**
1. Resolve queue file: `Path(os.environ.get("VAULT_VPS_PATH", "/srv/second-brain")) / "_system" / ".workshop-queue.jsonl"`. If the file does not exist, return silently.
2. Read all lines, parse each as JSON (skip blank/malformed). Filter to entries matching ALL of: `entry.get("action")`, `entry.get("confirmed") is True`, `not entry.get("dispatched", False)`.
3. If `_in_quiet_hours()` and any eligible entries exist: log "quiet hours — deferring N entries" and return without dispatching.
4. For each eligible entry:
   a. `verb = entry.get("action", "")`.
   b. If `verb == "post-to-telegram"`: call `telegram_alert.send_alert(entry.get("text", "(no text)"))` then `brain_http.mark_queue_entry_dispatched(entry["id"])`. Continue.
   c. If `verb == "link-orphans"`: call `brain_http.mark_queue_entry_dispatched(entry["id"])` (no-op dispatch — pre-approved, logged only). Continue.
   d. If `verb == "build"`: call `subprocess.run([sys.executable, "/opt/ultra-workshop/hermes-skills/workshop_build.py", entry.get("repo", ""), entry.get("task", "")], check=False)`. Then `brain_http.mark_queue_entry_dispatched(entry["id"])`.
   e. If `verb == "fix"`: call `subprocess.run([sys.executable, "/opt/ultra-workshop/hermes-skills/workshop_fix.py", entry.get("issue_url", "")], check=False)`. Then `brain_http.mark_queue_entry_dispatched(entry["id"])`.
   f. Unknown verbs: log a warning and `mark_queue_entry_dispatched` (to avoid infinite re-processing).

Imports at top: `import atexit, datetime, json, logging, os, subprocess, sys, time` and `from pathlib import Path`, then path-insert and imports of `telegram_alert` and `brain_http` from `/opt/ultra-workshop/hermes-skills/`.

`logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")` at module top.

**Acceptance:** `python hermes-skills/cron_bug_scan_fastpoll.py --help 2>/dev/null; python -c "import ast; ast.parse(open('hermes-skills/cron_bug_scan_fastpoll.py').read()); print('syntax ok')"` exits 0.

### Task 2: systemd unit file
**File:** `deploy/systemd/uws-bug-scan-fastpoll.service` (new)
**What:** Write the unit file with the following exact content:

```ini
[Unit]
Description=ultra-workshop bug-scan fast-poll (30s)
After=network.target uws-hermes.service

[Service]
Type=simple
User=uws
EnvironmentFile=/etc/uws/env
ExecStart=/opt/ultra-workshop/.venv/bin/python /opt/ultra-workshop/hermes-skills/cron_bug_scan_fastpoll.py
Restart=on-failure
RestartSec=10s
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

No other content. `After=uws-hermes.service` because the fast-poll calls Brain via `brain_http` which requires Hermes to be up for Telegram notifications (Brain itself is a separate service; this dependency is soft-ordering only).

**Acceptance:** `systemd-analyze verify deploy/systemd/uws-bug-scan-fastpoll.service 2>&1 | grep -c "error\|failed"` returns `0` (run locally if systemd available, or skip on macOS dev machine).
